# YouTube Ad Skipper

自動處理 YouTube 影片廣告的 Chrome 插件（Manifest V3）。

## 功能

- **可略過的廣告**：「略過」按鈕一出現就自動點擊
- **不能略過的廣告**：自動靜音並以 16 倍速播完
- **廣告結束後**：還原原本的音量和播放速度
- **頁面上的廣告區塊**：隱藏首頁、側欄和影片上的橫幅廣告

## 安裝

1. 打開 Chrome，網址列輸入 `chrome://extensions`
2. 開啟右上角的「**開發人員模式**」
3. 點「**載入未封裝項目**」，選擇這個資料夾
   - 在 WSL 中的路徑：`\\wsl$\<發行版名稱>\home\herry\project\youtube-ad-skipper`
   - 發行版名稱可在 Windows 用 `wsl -l` 查詢
4. 重新整理 YouTube 頁面

修改檔案後，到 `chrome://extensions` 按插件的 🔄 重新載入，再重新整理 YouTube。

> 移動資料夾後，需要先移除舊的插件，再從新路徑重新載入。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `manifest.json` | 插件設定與權限 |
| `content.js` | 偵測廣告、靜音加速、發現略過按鈕時請背景程式點擊 |
| `background.js` | 透過 `chrome.debugger` 送出真實的滑鼠點擊 |
| `content.css` | 隱藏頁面上的廣告區塊 |

## 運作原理與設計取捨

測試過幾種做法，結論如下：

| 做法 | 結果 |
|---|---|
| 用 `element.click()` 點略過按鈕 | ❌ YouTube 會檢查 `event.isTrusted`，直接忽略 |
| 把廣告跳到結尾（`currentTime = duration`） | ⚠️ 當下那支會過，但下一支廣告會卡住、不載入 |
| 只用 16 倍速播放 | ⚠️ 不會卡住，但長廣告常停下來等緩衝 |
| 用 `chrome.debugger` 送出真實點擊 | ✅ 可略過的廣告約 1 秒內就結束 |

因此目前的做法是：**所有廣告都靜音加速，可略過的廣告再用真實點擊按掉**。

### 為什麼要在 attach 之後才量按鈕位置

`chrome.debugger.attach` 會讓 Chrome 在上方顯示偵錯提示列，把整個網頁往下推。
如果在 attach 前就算好座標，點擊會落在按鈕上方而失效。
所以 `background.js` 會先 attach、等 300ms 讓版面穩定，再量按鈕位置並點擊。

## 已知限制

- 每次自動點擊略過時，Chrome 上方會短暫出現「已開始對這個瀏覽器進行偵錯」的提示列。這是 Chrome 強制顯示的，無法關閉。
- 不能略過的廣告不會瞬間消失，通常需要數秒到十幾秒（受緩衝速度影響）。
- YouTube 經常更改網頁結構，失效時通常需要更新 `content.js`、`background.js` 中的按鈕選擇器，或 `content.css` 中的廣告區塊選擇器。

## 除錯

- **頁面上的紀錄**：在 YouTube 按 F12 → Console，搜尋 `[AdSkipper]`
- **點擊相關的紀錄**：在 `chrome://extensions` 點插件的「service worker」連結，打開背景程式的 Console

常見訊息：

| 訊息 | 意思 |
|---|---|
| `已啟動` | 插件已在頁面上執行 |
| `偵測到廣告` | 廣告開始，已靜音加速 |
| `出現略過按鈕，送出點擊` | 已請背景程式點擊 |
| `已點擊略過按鈕` | 背景程式點擊完成 |
| `點擊失敗: ...` | 背景程式點擊時發生錯誤 |
| `廣告結束，還原設定` | 已還原音量與播放速度 |
